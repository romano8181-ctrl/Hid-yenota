# Хід Єнота

Настільні ігри для дітей від 5 років: хрестики-нулики, шашки, шахи (MVP), чотири в ряд, вовк і вівці, змії та драбини, мемо (хвиля 2), доміно, лудо, мельниця, манкала, реверсі (хвиля 3). Усього 12 ігор. Ведучий — єнот Рокі.
Специфікація: `SPEC.md`.

## Запуск (потрібен Node.js 20+)
```bash
npm install
npm run dev      # розробка: http://localhost:5173
npm test         # тести правил і ШІ
npm run build    # production-збірка (PWA, працює офлайн) у dist/
npm run preview  # перегляд збірки
```

## Структура
- `src/games/` — правила ігор. Ігри з ходами (`Game<S, M>`): хрестики-нулики, шашки, шахи (chess.js), чотири в ряд, вовк і вівці. Також `reversi`, `mill`, `mancala`. Ігри з кубиком, пам'яттю чи прихованою інформацією (`snakes`, `memory`, `domino`, `ludo`) мають чисту логіку й власні екрани.
- `src/ai/` — minimax з альфа-бета, 5 рівнів складності, Web Worker.
- `src/ui/` — карта ігор, екран гри, дошки, Рокі.
- `src/i18n/uk.ts` — усі тексти (для англійської додається `en.ts`).
- `src/speech.ts` — голос Рокі (поки браузерний синтез uk-UA, потім аудіофайли).

## Відомі обмеження MVP
- Шахи: пішак завжди стає ферзем.
- Голос — вбудований синтез браузера, якість залежить від пристрою.
- Іконки PWA — тільки SVG; PNG 192/512 для магазинів додаємо пізніше.
- Графіка поки емодзі та SVG-примітиви; персонажі від ШІ — наступним кроком.

## Публікація (GitHub Pages)
1. Створи репозиторій на GitHub і завантаж туди проєкт (гілка `main`).
2. У репозиторії: Settings → Pages → Source: **GitHub Actions**.
3. Після кожного пушу в `main` workflow `.github/workflows/pages.yml` запускає тести, збирає застосунок і публікує його.
   Адреса: `https://<твій-логін>.github.io/<назва-репозиторію>/`.
